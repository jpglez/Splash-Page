# 🌐 Splash Page – Everything You Want

A **visual concept splash page** for a mobile shopping app available on **Apple** and **Android**.  
This project showcases the **UI design and presentation** of a next-generation marketplace where you can find everything — from **gaming gear** to **home essentials** — all in one place.

---

## ✨ Overview
This splash page was built as a **visual prototype**, not a full app.  
Its goal is to present:
- A modern and responsive layout  
- App Store & Google Play download mockups  
- A clear, minimal hero section  
- Brand identity and tagline preview  

---

## 🧱 Built With
- **HTML5**  
- **CSS3**  
- **Vanilla JavaScript**

---

## 🚀 Purpose
The project serves as a **front-end visualization** of what the mobile app’s promotional landing would look like.  
It’s perfect for presentations, product previews, or UI showcases.
